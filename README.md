# KT그룹 통합광고 LiveAD+ — 방송광고 송출예정 대시보드

큐톤광고(송출시간이 불안정한 방송광고)의 **송출 예정 시간을 광고주에게 미리 안내**하는 서비스입니다.

## 문제와 해결

광고주는 자신의 큐톤광고가 정확히 언제 나갈지 알기 어려워 방송을 놓치고, 확인 문의가 반복되어 방송매체사의 업무 부담이 늘어납니다.

이 서비스는 cjenm.com의 큐톤 예정 사이트(tvN 계열·OCN 계열·중화TV·Tooniverse·Mnet 등 11개 채널)를 매일 자동으로 수집하고, 관리자가 업로드한 편성현황 엑셀과 시간 슬롯 기준으로 매칭해 송출 예정 결과를 산출합니다. 관리자가 매칭 결과를 확인하고 최종 승인하면, 광고주는 대시보드에서 본인 담당 광고의 송출 예정 시각을 조회하고 엑셀로 다운로드할 수 있습니다.

## 핵심 기능

- **큐톤 예정 데이터 자동 수집·매칭** — cjenm.com 11개 채널의 초 단위 큐톤 시각을 편성현황 엑셀의 30분 슬롯과 자동 매칭 (불일치 항목은 별도 표시)
- **관리자 대시보드** — 채널별·광고주별 송출 횟수 그래프, 날짜별 조회, 광고주명 검색, 매칭 결과 엑셀 다운로드(화면에 보이는 결과만 정확히 반영)
- **송출 예정 알림** — 관리자 최종 승인 즉시 광고주에게 이메일로 자동 안내 (발송 실패 시 관리자에게 통지)
- **광고주 셀프 조회** — 로그인한 이메일과 담당자 이메일이 일치하는 오늘~내일 확정 스케줄만 조회·다운로드

## 기술 스택

| 구성 요소 | 역할 |
|---|---|
| [Next.js](https://nextjs.org) | 화면(프론트엔드)과 서버 API를 한 프로젝트로 통합 처리 |
| [Supabase](https://supabase.com) | 데이터 저장 및 RLS(행 단위 보안) 기반 접근 제어 |
| [Resend](https://resend.com) | 송출 예정 알림 이메일 발송 |
| [Vercel](https://vercel.com) | 배포 및 매일 자동 수집(Cron) 스케줄링 |

## 로컬 개발

```bash
npm install
npm run dev
```

`.env.local`(또는 `.env`)에 아래 환경변수가 필요합니다.

```
NEXT_PUBLIC_SUPABASE_URL=
NEXT_PUBLIC_SUPABASE_ANON_KEY=
SUPABASE_SERVICE_ROLE_KEY=
CRON_SECRET=
```

## 보안

- 대외비 서비스로, 광고주 본인과 방송매체사 담당자 외에는 접근할 수 없습니다.
- 모든 민감 테이블은 Supabase RLS로 기본 차단되며, 서버(Service Role)만 조회할 수 있습니다.
- 광고주는 로그인 이메일과 등록된 담당자 이메일이 서버 단에서 일치하는 경우에만 본인 데이터를 조회합니다.
